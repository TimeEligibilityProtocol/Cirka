# Pakiet wearto.you v10 — Identity Payout

## Zatwierdzony model

- Brak portfela użytkownika wearto.you.
- Payout jest adresowany do zweryfikowanej osoby przez e-mail lub numer telefonu.
- Sprzedawczyni wybiera e-mail albo WhatsApp jako kanał claim.
- Tap albo Lean wykonuje rzeczywisty transfer i split 90/10.
- Marketplace nie wykonuje ręcznych przelewów i nie przechowuje pełnych danych finansowych.
- wayto.you obsługuje identity routing, claim flow i dwustronne bezpieczeństwo.
- QR odbioru osobistego jest częścią MVP; sześciocyfrowy kod jest fallbackiem.
- In-app/web push obsługuje oferty i bieżące zdarzenia.
- Komunikację dotyczącą przyjazdu i trasy kuriera prowadzi zintegrowany operator kurierski.
- Krypto i PayPal nie należą do produktu.
